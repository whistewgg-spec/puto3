# 🖥️ Virtual PC

PC virtual completo no browser via GitHub Codespaces.
Windows 10/11 ou Linux KDE — sem instalação, sem hardware.

## Setup

1. Fork / clone este repo
2. Abre um Codespace (**Code → Codespaces → New**)
3. Aguarda o setup automático (~5 min)
4. Porta `8006` → Windows | Porta `6080` → Linux

## Recursos

| OS | Porta | Acesso |
|----|-------|--------|
| Windows 10 | `8006` | noVNC |
| Linux KDE | `6080` | noVNC |
| Windows RDP | `3389` | RDP nativo |

Baseado em [dockurr/windows](https://github.com/dockurr/windows) e [linuxserver/webtop](https://github.com/linuxserver/docker-webtop).
